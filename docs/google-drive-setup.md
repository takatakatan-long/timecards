# Google Drive 同期の準備

スマホと PC でデータをやり取りするために、Google 側でこのアプリを登録する。
この作業は 1 回だけで、アプリの利用者本人が行う（開発者が代行できない）。

登録が済むまで、アプリに同期の機能は表示されない。

---

## 1. Google Cloud のプロジェクトを作る

1. https://console.cloud.google.com/ を開き、Google アカウントでログインする
2. 画面上部のプロジェクト選択 → 「新しいプロジェクト」
3. 名前は何でもよい（例: `timecards`）。作成したら、そのプロジェクトを選んだ状態にする

## 2. Google Drive API を有効にする

1. 左メニュー「API とサービス」→「ライブラリ」
2. `Google Drive API` を検索して開き、「有効にする」

## 3. アプリの登録（OAuth 同意画面）

1. 左メニュー「API とサービス」→「OAuth 同意画面」
2. User Type は **外部** を選ぶ（組織アカウントでなければこれしか選べない）
3. アプリ名（例: 出勤簿）、サポートメール、開発者の連絡先メールを入れる
4. スコープの追加で `.../auth/drive.file` を選ぶ
   - **このアプリが作ったファイルにしか触れない権限**。Drive の他の中身は読めない
   - 審査が要る「機密スコープ」には当たらないので、Google の審査を待たずに使える
5. 最後に「アプリを公開」する（**テスト中のままにしない**）
   - テスト中のままだと、許可が 7 日で切れて頻繁に接続し直すことになる

## 4. OAuth クライアント ID を作る

1. 左メニュー「API とサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
2. アプリケーションの種類: **ウェブ アプリケーション**
3. 「承認済みの JavaScript 生成元」に次の 2 つを追加する

   ```
   https://takatakatan-long.github.io
   http://localhost:5173
   ```

   - 上が公開しているアプリ、下が開発中に手元で動かすときのもの
   - 「承認済みのリダイレクト URI」は空のままでよい（この方式では使わない）
4. 作成すると **クライアント ID** が表示される（`....apps.googleusercontent.com` で終わる文字列）
   - これは秘密の値ではない。ブラウザに配られる前提の識別子なので、公開されても問題ない

## 5. クライアント ID をアプリに渡す

### 公開されているアプリに反映する

1. https://github.com/takatakatan-long/timecards/settings/variables/actions を開く
2. 「New repository variable」
3. Name: `VITE_GOOGLE_CLIENT_ID` ／ Value: 手順 4 のクライアント ID
4. 保存したあと、次に `main` へ push すると反映される
   - すぐ反映したい場合は Actions タブから `Deploy to GitHub Pages` を手動実行する

### 手元で試す場合

`.env.example` を `.env.local` という名前でコピーし、クライアント ID を書く。
`.env.local` は Git に入らない設定にしてある。

---

## 使い方

1. 設定 → Google Drive →「Googleアカウントに接続」
2. 「このアプリは確認されていません」と出た場合は、詳細 → 続行を選ぶ
   - 自分で登録したアプリなので、この表示が出るのは正常
3. ホームの「同期」を押すと、Drive とやり取りする

**同期は自動では行わない。** 押し忘れに気づけるよう、ホームに最終同期日時と未同期件数を出している。

もう 1 台でも、同じ Google アカウントで同じ手順を行えば、記録が揃う。

## Drive 上の置き場所

```
マイドライブ/
  出勤簿/
    config.json     設定（丸め規則・現在の期・事業者名）
    terms.json      期の一覧
    staff.json      スタッフと時給
    records/
      2026-08.json  月ごとの勤怠
      2026-09.json
```

月ごとにファイルを分けているのは、2 台で同時に触ったときに競合する範囲を狭めるため。
突き合わせは記録 1 件ずつ行い、更新時刻の新しい側を採る。
そのため、2 台が別々の行を直していても、どちらの入力も消えない。

## 接続が切れたとき

この方式の許可は 1 時間ほどで切れる。切れると設定画面が「接続が切れています」に変わり、
ホームの同期欄にも警告が出る。「接続し直す」を押せば元に戻る。

手動同期のため、切れたまま気づかず「同期したつもり」になるのを防ぐ目的で、
未接続とは別の状態として扱っている。

## 注意

- Drive 同期は 2 台を揃える仕組みであって、バックアップではない
  - 片方で消した記録は、同期するともう片方からも消える
  - 別途バックアップ機能を用意する予定
